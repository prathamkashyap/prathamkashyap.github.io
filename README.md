## ✨ Features & Architecture

- **🪐 3D Celestial Singularity & Accretion Nebula (Three.js)**:
  - 800+ dynamic accretion disk particles with mathematical orbital velocity gradients.
  - Multi-axis concentric gyroscopic celestial rings responding dynamically to mouse parallax.
  - Locked 60fps performance with GPU compositor layer promotion.
- **🎵 Harmonic Web Audio Synthesizer**:
  - Real-time pure sine harmonic synthesizer (528Hz, 792Hz, 1056Hz) producing soothing ambient celestial chimes on user interaction.
  - Built natively with Web Audio API (`window.AudioContext`) without external audio file dependencies.
  - Accessible global audio toggle `[🔊 SFX: ON/OFF]`.
- **⚡ 2×2 Geometric Technology Constellation Matrix**:
  - 4 distinct celestial geometries: *Cassiopeia Starlight Lightning*, *Neural Starburst Nexus*, *Double Helix Quantum Gateway*, and *Crescent Moon Orbit*.
  - Frosted SVG backdrop pills eliminating text overlap and dimming background stars.
- **💻 macOS Glass Code Terminal**:
  - Full-height syntax-highlighted IDE terminal with interactive execution logs and system telemetry.
- **📊 Architectural Telemetry Stream**:
  - Precision telemetry cards detailing applied ML research models, decision trees, and empirical performance metrics.
- **🚀 Asteroid Defender Arcade Mini-game**:
  - Integrated retro-futuristic canvas mini-game with score tracking and collision physics.

## 🚀 Local Development

This portfolio requires **zero build steps or package managers** to run.

### Option 1: Python HTTP Server (Built-in)
```bash
# Clone the repository
git clone https://github.com/prathamkashyap/prathamkashyap.github.io.git
cd prathamkashyap.github.io

# Start local server
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Node.js / npx
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and select **"Open with Live Server"**.

## 🌐 Deployment

### Deploy to GitHub Pages
1. Push this repository to GitHub as `prathamkashyap.github.io`.
2. Go to **Settings → Pages** → select branch `main` and root `/`.
3. Your site will automatically go live at **`https://prathamkashyap.github.io`**.

### Deploy to Vercel
1. Go to [vercel.com](https://vercel.com) and click **Add New → Project**.
2. Import `prathamkashyap/prathamkashyap.github.io`.
3. Keep default settings (Framework: `Other`, no build command needed) and click **Deploy**.
4. Your site will be live at **`https://prathamkashyap.vercel.app`**.
